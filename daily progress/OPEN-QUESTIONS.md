### 困惑 1：为什么没有 uvicorn 就访问不到 `/api/health`

- **我的答法**："不能，但不知道为什么。"
- **差在哪**：结论对，机制缺。`import app.main` 只是把 `app` 对象加载进内存然后退出，**没有进程占住 8000 端口、没有进程在等连接**。`app` 是"柜台和规矩"，uvicorn 才是"开门迎客的人"。
- **怎么验**：不启动 uvicorn，直接在浏览器访问 `http://127.0.0.1:8000/api/health`，看到"无法访问此网站"；再启动 uvicorn，同一个地址立刻返回 JSON。
- **状态**：待验证

### 困惑 2：少传 `verdict` 时那个 422 到底是谁产生的

- **我的答法**："Pydantic 里面写明什么情况返回什么数字，固定好了。"
- **差在哪**：Pydantic 不"写死数字"，它只抛校验错误；**是 FastAPI 把校验错误统一映射成 422**（HTTP 语义里 422 = 请求体格式/语义有误）。我一行代码都没写，这行"代码"是声明自动换来的。
- **怎么验**：`/docs` 里删掉 `verdict` 提交，看返回的 `detail` 是 `{"type": "missing", "loc": ["body","verdict"], "msg": "Field required"}` —— **这段 JSON 不是我写的**，是框架按声明生成的。
- **状态**：待验证

### 困惑 3：`return` 的字典和浏览器看到的 JSON 是不是同一个东西

- **我的答法**："这两个是一个东西吧。"
- **差在哪**：**不是。** 一个是内存里的 Python 字典对象，一个是文本字符串。中间由 **FastAPI 做序列化**（dict → JSON 文本）并补 `200` 和 `Content-Type: application/json`。像"脑子里的苹果"和"纸上写苹果"的区别——以后 Java 那边收到的永远是文本。
- **怎么验**：在函数里临时加一行 `print(type(result))`，日志里看到的是 `<class 'dict'>`；浏览器里看到的却带双引号——同一次请求，两种形态。
- **状态**：待验证

### 困惑 4：`source_code` 传 `"   "`（三个空格）该由谁拦住

- **我的答法**："规则吧可能，我不知道谁拦。"
- **差在哪**：**由我在路由函数里写 `if` 拦**，具体是 `if not req.source_code.strip():` 然后 `raise HTTPException(status_code=422, ...)`。Pydantic 拦不住是因为 `"   "` 是合法字符串、长度也没超，**声明能表达的约束它全满足了**；"有没有意义"只有人懂。
- **怎么验**：`/docs` 里 `source_code` 填三个空格 → 422，且 `detail` 是**我自己写的那句话**（不是 `Field required`）。能区分这两句话，就说明我分清了两条路。
- **状态**：待验证

### 困惑 5：`health` 这个名字和访问路径是什么关系

- **我的答法**："修饰的就是访问路径 health，health 只是接口名字，为了区分别的路径。"
- **差在哪**：装饰器括号里的**字符串** `"/api/health"` 才是被登记的东西；`def health()` 里的 `health` 只是函数名，**不参与路由**。同名只是命名习惯，不是"为了区分路径"。
- **怎么验**：把装饰器改成 `@app.get("/api/xyz")` 而函数仍叫 `health` → 访问 `/api/health` 变 404，`/api/xyz` 通。反过来函数改名也不影响地址。
- **状态**：✅ 已通（2026-11-20）。路径由装饰器里的字符串决定、函数名不参与路由；11/19 深夜重敲 main 时把路径误写成 `/app/health`，实测 `/api/health` 返回 404、`/app/health` 返回 200，即为证据。函数改名（`health` → `ping`）不影响地址，用户已自行推出该结论。

### 困惑 6：GET 和 POST 的真正分界线

- **我的答法**："GET 是输出给用户的，POST 是用户输出给我们的。"
- **差在哪**：大方向可用，但**两者都会返回响应**（POST 也有结果 JSON），GET 也能带少量查询参数。真正硬的两条：① **改不改服务端状态**（GET 只读，POST 可能新建记录）；② **数据放 URL 还是放请求体**（决定能不能传大段源码、会不会被日志记录）。
- **怎么验**：把 `/api/analyze` 临时改成 `@app.get`，/docs 里会发现字段全部变成网址参数——直观看到"数据位置"的差别。
- **状态**：待验证
