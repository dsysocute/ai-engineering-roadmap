# 练习目录（语法 / 基础刷题，不是简历项目）

> 这里放阶段 0–1 的语法和基础练习代码，用来找编程感觉、巩固知识点。**练习不算项目**，简历上只写能讲清角色、模块、实现的正式项目（电商 Java、AI Demo、数据清洗管线）。

## 目录

| 目录 | 放什么 | 对应阶段 |
| --- | --- | --- |
| `java-se/` | Java 语法、OOP、集合、常用类等 SE 练习 | 阶段 0、1 |
| `python/` | Python 基础、FastAPI 接口小练习 | 阶段 0、3 |
| `sql/` | SQL 练习题与答案（DDL/DML/DQL、join、聚合、窗口函数） | 阶段 0、2 |

## 命名规则

按知识点编号，一个练习一个文件，文件名见名知意：

- Java：`01-变量与数据类型.java`、`02-数组与循环.java`、`03-面向对象入门.java`
- Python：`01-函数与异常.py`、`02-FastAPI-hello.py`
- SQL：`01-两表连接查询.sql`、`02-聚合与分组.sql`

## 规则

1. 代码自己敲，AI 只答疑、review、查文档，不直接贴成品。
2. 每题先口述思路再写代码；写完讲时间/空间复杂度，记边界情况。
3. 卡住或答错说不出理由，记到 `../daily progress/OPEN-QUESTIONS.md`，写清"怎么验"。
4. 练习代码可以提交，作为学习轨迹；`.venv/`、`*.class`、`out/` 已在根目录 `.gitignore` 忽略，不要提交。
5. 同一个知识点练到能脱稿讲清，再往下走；别囤一堆跑不通的文件。
