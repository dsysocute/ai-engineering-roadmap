程序规范

仅需定义类 Solution，实现方法 public void sort(int[] arr)，完成数组升序排序。无需返回值，无需实现接口，不要添加 static 修饰符。

public class Solution {
    public void sort(int[] arr) {
        // 在此处编写排序代码
    }
}

禁止编写 main 方法、Scanner 输入及 System.out 输出语句。平台直接传入数组，不通过控制台交互。 方法名错误、方法签名不符或添加 static 修饰符，均会导致加载失败。

测试运行

  • 点击【测试运行】执行 4 组测试样例：单元素数组、完全逆序数组、大量重复元素数组、随机数组
  • 逐组输出通过 / 未通过，并显示排序前、排序后的数组内容，便于对照排查
  • 测试样例规模较小，全部通过不代表正式评测可以通过

判题规则

  • 正确性用例共 5 组，规模 1000 至 10000，覆盖随机、已排序、完全逆序、大量重复等情况
  • 5 组全部通过方可得分，任一组未通过总分为 0
  • 正确性通过后进行效率评测：十万级规模 3 组，与平台内置归并排序比较运行耗时
  • 效率评测在后台异步执行，提交后无需等待
