测试运行

  • 点「测试运行」跑 4 组小样例：单个元素、7 个完全逆序、20 个大量重复、200 个随机数
  • 逐组给出 ✅ 通过 / ❌ 未通过，并显示排序前、排序后的数组，方便自己对照
  • 测试通过 ≠ 正式交卷一定通过：正式判题还有 1000/10000 规模的五组用例

判题规则

  • 正确性五组：1000 随机、10000 随机、10000 已排序、10000 完全逆序、10000 大量重复
  • 五组全过才算正确，否则总分 0
  • 效率三组：10 万规模随机 / 已排序 / 逆序，和平台内置归并排序比耗时（后台异步测算）
