> 大二 · 数据科学与大数据技术 · 目标：**寒假拿到大模型应用 / Agent 开发实习**
> 主投：泛联新安《大模型应用开发实习生》（120–150/天，3 天/周 × 3 个月）　|　冲刺：新星项目《AI Agent 研发实习生》（150–300/天）

## 三、掌握方式标注

- **［必学手搓］**：必须自己会敲命令、会写代码、能逐行解释；面试会被深挖，不能靠 AI 代劳。
- **［可AI辅助］**：可让 AI 出初稿或答疑排错，自己负责设计、看懂、验收和讲清原理；现成框架与库直接调用即可。

## 五、红线与取舍

1. 数学分析重修是学业红线，下学期冲刺期主动降速，不再挂科。
2. **LangGraph / RAG 已修正为必学**（三份原始 JD 均列为任职要求）：LangGraph 在 M3 用框架重写一遍同一套三工具 Agent；RAG 做最小原型；MCP / Memory / 多 Agent 仍只做概念，12/18 前不碰。
3. 不大规模重构原有 Java 判题代码；新增 AI 能力全部隔离在 Python 服务。
4. 不让 AI 写完代码直接入库；新增代码必须逐行理解，能讲清请求如何进来、数据如何处理、结果如何返回。
5. 雅思与外企规划后置，当前不分配固定备考时间。
