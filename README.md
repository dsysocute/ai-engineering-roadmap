# AI Engineering Roadmap

> 大二 · 数据科学与大数据技术 · 全周期路线：**工程底座 → 第一段实习破零（2027 暑假）→ 内功与后端深化 → 第二段实习 → 秋招 / 考研兜底**
> 主线项目：电商 Java（作业 + 学长推荐项目，主线练手）+ AI 全栈 Demo（Python 后端 + 前端页面 + 大模型 / RAG / 工具调用链路）；AlgoArena 排序平台搁置备查。

## 一、当前定位

本仓库用于沉淀从 Python/Java/SQL 基础、前端联调到 AI 应用落地的学习过程与项目产出。代码以能跑通、能逐行解释为准，不追求框架堆砌。

> **路线说明（2026-11-26 修订）**：主轨就业 **AI 全栈开发**，备选考研兜底——后端 Python 主线 + Java 二线打底，补前端到能做页面和联调，叠加大模型 / RAG / 工具调用等 AI 应用能力；不单独设 Agent 开发岗位方向。规划从当前学期一直排到毕业，2027 暑假实习只是第一个节点。阶段任务、JD 对标与验收标准详见 [ROADMAP.md](./ROADMAP.md)（唯一维护源）；详细执行规划见 [PLAN-2027暑假实习.md](./PLAN-2027暑假实习.md)；当前进度落点见 [CURRENT-STATUS.md](./CURRENT-STATUS.md)。

## 三、掌握方式标注

- **［必学手搓］**：必须自己会敲命令、会写代码、能逐行解释；面试会被深挖，不能靠 AI 代劳。
- **［命令辅助］**：建目录、venv、装依赖、Git 提交、跑测试、环境排障属命令项，可给命令执行。
- **［可AI辅助］**：配置模板可由 AI 出初稿，自己负责看懂、验收和讲清原理。

## 五、红线与取舍

1. 数学分析重修是学业红线，冲刺期主动降速，不再挂科。
2. 底座优先：Python/Java、SQL、API/后端、调试能力先打牢，再补前端联调与 LLM/RAG/工具调用等 AI 应用能力，不押单一岗位名头。
3. 搁置的 AlgoArena 不重构、不推进；主线电商与 AI Demo 的代码逐行理解后再入库。
4. 不让 AI 写完代码直接入库；新增代码必须逐行理解，能讲清请求如何进来、数据如何处理、结果如何返回。
5. 副业 / 创业只做低成本验证，不占主线时间；雅思与外企规划后置，当前不分配固定备考时间。
